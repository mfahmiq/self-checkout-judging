# The Self-Checkout Is Judging You

One line, 71 characters, in the voice of a smug self-checkout machine judging a shopper who bought twelve yoghurts and nothing else.

> Unexpected item in your personality: twelve yoghurts. Please remove it.

Why this line wins (judge brief, in weight order):

- **Machine voice, first and foremost:** it *is* the machine's own error message — "Unexpected item in the bagging area" — turned back on the shopper, ending with the machine's literal command, "Please remove it."
- **Real laugh on a single read:** the twist lands cold with no context — the "unexpected item" isn't in the bagging area, it's the shopper's personality.
- **Smug and petty about the basket:** twelve yoghurts, nothing else, treated as a defect to be removed from the belt.
- **Tight:** 71 characters, three beats, every word earns its place — no setup padding, no "this week" framing.
- **Fresh:** the "unexpected item" phrase is iconic, but aiming it at the shopper's personality instead of the bagging area is a new turn on it.

Run `python3 main.py` — it writes the line to `/output/entry.txt` and prints it.
